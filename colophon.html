How This Page Reaches You

This site is one HTML file and one CSS file — 6.9 KB total, two requests, no JavaScript, no cookies. Everything else you're about to read is what makes those 6.9 KB actually arrive at your screen.

1. The lookup

Your browser asks a resolver where aurelien.goulon.net lives. This zone is DNSSEC-signed, so the resolver doesn't just take the answer on faith — it validates a signature chain back to the root. If anything between here and there tried to hand you a forged address, the chain would break and the lookup would fail closed instead of silently succeeding.

2. The answer

What comes back is a Cloudflare anycast address — the same handful of IPs that answer for millions of other domains. Which physical data center actually responds isn't decided by me; it's decided by BGP, live, based on whichever announcement of that address is topologically closest to you. Someone in Calgary and someone in Marseille get routed to two different buildings without either of us configuring anything.

3. The handshake

Your browser opens a TLS 1.3 connection to that address. Cloudflare terminates the encryption at the edge — the data center nearest you, not a server I run — and negotiates HTTP/2 or HTTP/3 depending on what your client offers. This is also where CAA records matter: they constrain which certificate authorities are even allowed to issue a certificate for this domain, so a compromised or careless CA elsewhere on the internet can't mint one nobody authorized.

4. The cache, or the origin

If the edge already has this page cached, it answers immediately and none of the next step happens. If not, it fetches from the origin: a static HTML file sitting in a public git repository, published by GitHub Pages on every push to the main branch. There is no server I have to patch, restart, or lose sleep over — the origin is a file, not a process.

5. What lands on your screen

The response comes back through the same edge, gets cached there for the next visitor, and arrives in your browser as two files and nothing else. No render-blocking scripts, no third-party requests, no layout shift while something loads in late.

What it costs

$0 a month. The only recurring cost is the domain registration itself, paid yearly to the registrar. Hosting, TLS, DDoS protection, DNSSEC signing, and the global anycast network in between are all free at this scale.
